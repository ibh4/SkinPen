# SkinPen 显示逻辑说明（含完整坐标 / 尺寸 / 字号）

对应文件：`gui_preview.html`（网页模拟器，1:1 还原固件 gui.c + V0.5 新结果页）
所有数值与 `gui_preview.html` CSS 逐项一致，可直接作为固件 LVGL 布局参数。

---

## 0. 整体分辨率与坐标系

| 项 | 值 |
|---|---|
| 逻辑分辨率 | **320 × 172**（宽 × 高，横屏） |
| 坐标系 | 原点 (0,0) 在**左上角**，x 向右 0~319，y 向下 0~171 |
| USB 口方位 | 设备右侧（握持时屏幕上下颠倒即 USB 在左，注意勿镜像） |
| 色深 | RGB565 |
| 框架 | LVGL 8.4，浅色主题，白底 #FFFFFF |
| 元素定位 | 全部绝对定位 (x, y)，元素尺寸 w×h |

主题色：
`--ink #2C3E50`(黑/主文字) · `--sub #888888`(灰/次要) · `--acc #3B6FB5`(蓝/强调) · `--card #F5F7FA`(浅灰底) · `--ok #2E7D32`(绿) · `--warn #E67E22`(橙) · `--err #C62828`(红)

字体字号规范（LVGL）：
| 字号 | 用途 |
|---|---|
| 12px (montserrat) | 色块下方小代码、HEX 值 |
| 16px (montserrat / font_zh_16 中文) | 按钮小字、列表行、标签、提示 |
| 20px (montserrat) | 主按钮文字、页标题、测量页文字 |
| 22px (montserrat) | 主页序号进度 |
| 26px (montserrat) | 主页色号、结果页色号（最大强调文字） |

按钮通用样式：白字、圆角 10px、按下变暗（brightness 0.9）。

页面流转：
```
开机 ──▶ 启动页(1.5s 自动) ──▶ 主页 ◀────────────┐
                          │                      │
             ┌────────────┼──────────┐           │
             ▼            ▼          │           │
          选择页        测量页 ───────┘(10帧自动) │
         (LIST)       (MEASURE)                 │
             │            │                     │
        点行/返回 ←── 返回键                 结果页
                          ├─ V0.5 → result2（新：皮肤/粉底/口红 三大色块）
                          └─ V0.4 → result （旧：色号+粉底3格+口红1格）
         所有子页返回键 → 主页
```
